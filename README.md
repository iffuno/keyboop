# Keyboop

> **wrong layout? keyboop.**
> Бесплатный open-source переключатель раскладки для macOS, который чинит
> кракозябры — и при этом **не трогает твой буфер обмена**.

Набрал `ghbdtn` вместо `привет`? Keyboop молча всё расколдует. Хочешь — автоматически,
хочешь — по горячей клавише (последнее слово, последние N слов или всё, что
настучал за последние T секунд). Плюс автозамена сниппетов: набрал сокращение —
получил e-mail, подпись, любую фразу. И голосовой набор — локально, на устройстве.

Сайт: **[keyboop.com](https://keyboop.com)**

## Чем отличается

- 🧼 **Не ломает буфер обмена.** Главная болезнь Punto Switcher — clipboard.
  Keyboop печатает исправленный текст напрямую (Backspace + Unicode), буфер не трогает вообще.
- ⏪ **Гибкое окно отката.** Не только последнее слово, а N слов / фраза / время — одним хоткеем.
- ✍️ **Сниппеты + раскладка в одном.** Автозамена аббревиатур, как у Punto/Espanso.
- 🎤 **Голосовой набор.** Локальное распознавание (whisper.cpp / Parakeet), без облака.
- 🔒 **Локально и приватно.** Ничто из набранного, надиктованного и поведения не покидает
  устройство — ни телеметрии, ни «дневника» нажатий. Сеть только для скачивания моделей
  (по кнопке) и проверки обновлений.
- 🍎 **Современно.** Apple Silicon (macOS 14+), нотаризовано Developer ID, авто-апдейты (Sparkle).

## Сборка

Прямая сборка через `swiftc` (без Xcode): `bash build-app.sh` → `Keyboop.app`.
Нужны vendored-зависимости (не в репозитории из-за размера): `whisper.cpp`,
`Sparkle`, FluidAudio — см. `THIRD_PARTY.md`. Релиз с нотаризацией — `release.sh`
(нужен свой Developer ID + профиль notarytool).
