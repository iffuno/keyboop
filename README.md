## Keyboop

wrong layout? keyboop.
Безкоштовний open-source перемикач розкладки для macOS, який виправляє
кракозябри — і водночас не чіпає твій буфер обміну. А ще набирає
текст голосом. Повністю на твоєму Mac.

Набрав ghbdtn замість привіт? Keyboop мовчки все розчаклує — прямо під час
набору або на межі слова. Не вгадав — виправ хоткеєм: останнє слово,
останні N слів або все, що настукав за останні T секунд. Плюс автозаміна
сніпетів та локальна диктовка.
## Чим відрізняється

* 🧼 Не ламає буфер обмена. Головна хвороба Punto Switcher — clipboard.
Keyboop друкує виправлений текст напряму, буфер не чіпає взагалі.
* 🎙 Голосовий набір — локально. Whisper та Parakeet (Neural Engine) на твоєму
Mac: затиснув хоткей, продиктував, відпустив — текст на місці. Жодного байта в мережу.
* 🌐 Переклад виділеного. ⌃⌥T — переклад стає на місце виділення, через
Apple Translation, теж на пристрої (macOS 15+).
* ⏪ Гнучке вікно скасування. Не тільки останнє слово, а N слів / фраза / час —
одним хоткеєм. Цього немає ні в кого.
* ✍️ Сніпети. Набрав скорочення — отримав e-mail, підпис, будь-яку фразу.
Розкладка та регістр не важливі.
* 🔒 Локально та приватно. З того, що ти друкуєш і говориш, назовні не
йде нічого. Open source — можна перевірити кожне слово.
* 🍎 Сучасно. Apple Silicon, нотаріально завірено Apple, автооновлення, свій
канал фідбеку прямо з додатка.

## Встановлення
Завантаж DMG на keyboop.com — перетягни в Програми,
дозволь доступ до клавіатури, для голосу вибери модель. Оновлюється саме.
Потрібно: Mac на Apple Silicon (M1 і новіше), macOS 14+.
## Збирання з вихідного коду
Потрібні Xcode Command Line Tools та три зовнішні залежності — їхній код чужий, до цього
репозиторію він не входить, поклади поруч у vendor/:

mkdir -p vendor && cd vendor
# 1. whisper.cpp — розпізнавання мовлення.
git clone https://github.com/ggml-org/whisper.cpp
cd whisper.cpp
cmake -B build-macos14 -DCMAKE_OSX_DEPLOYMENT_TARGET=14.0 -DCMAKE_BUILD_TYPE=Release \
  -DBUILD_SHARED_LIBS=OFF -DWHISPER_BUILD_EXAMPLES=OFF -DWHISPER_BUILD_TESTS=OFF \
  -DWHISPER_BUILD_SERVER=OFF
cmake --build build-macos14 -j
cd ..

⚠️ Прапорець CMAKE_OSX_DEPLOYMENT_TARGET=14.0 є обов'язковим. Без нього cmake бере версію
тієї системи, на якій ти збираєш, і ggml-metal жорстко зв'язується з класом із
macOS 15 — на macOS 14 додаток мовчки помре ще до main(). Перевірено на живих
користувачах, лагодилося екстреним релізом.
Ще дві:

* Sparkle (автооновлення) → vendor/sparkle/Sparkle.framework —
[релізи](https://github.com/sparkle-project/Sparkle/releases)
* FluidAudio (Parakeet на Neural Engine) → vendor/fluidaudio-prebuilt/ з
libFluidAudio.a, Modules/ та include/ —
[вихідний код](https://github.com/FluidInference/FluidAudio)

Далі:

bash build-app.sh      # dev-збірка (self-signed) → Keyboop.app
bash install-local.sh  # те саме + встановлення в /Applications

Готові релізи підписані Developer ID та нотаріально завірені Apple — скрипт релізу зав'язаний
на особисті ключі і до репозиторію не входить.
